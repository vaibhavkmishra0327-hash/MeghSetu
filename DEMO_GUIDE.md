# SIH presentation guide
1. Start the Python API and frontend using the local setup in README.md.
2. Open http://localhost:5173. Explain that the included rainfall data are generated samples.
3. Click **Run analysis** to regenerate data, train and refresh results.
4. On Overview, introduce the workflow and held-out model comparison.
5. Open Rainfall map, select a layer and click a marker to inspect the model output.
6. Open Weather patterns to show regime counts and feature importance.
7. Open Forecast comparison to compare raw NWP, global correction and pattern-specific correction.
8. Open Heavy rain watch and adjust the threshold to explore ranked sample locations.
9. Finish on Verification. Explain that metrics show the pipeline working on generated data, not operational forecast skill.
